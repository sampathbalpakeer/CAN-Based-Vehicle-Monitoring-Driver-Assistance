# GitHub Upload Steps

## 1. Create the repository

Create a new GitHub repository named:

`CAN-Based-Vehicle-Monitoring-Driver-Assistance`

If your institute requires a public repository, select **Public**. Otherwise follow the institute's privacy requirement.

Do not create an additional README during repository creation because this package already contains the final README.

## 2. Upload the project

Upload the contents of this folder so that the repository root contains:

```text
README.md
.gitignore
src/
docs/
```

Do not create an extra level such as:

```text
repository/CAN_Vehicle_Monitoring_GitHub_Ready/src/
```

The `src` and `docs` folders should be directly under the repository root.

## 3. Check the GitHub page

After uploading, confirm that GitHub displays:

- README project title and description
- System block diagram
- Wiring reference
- Three node folders
- Documentation files
- Output screenshots

## 4. Before final submission

Verify the following against the physical project:

- DS18B20 DQ = P0.20
- Actual ultrasonic sensor model
- Actual circuit schematic
- Final reverse SAFE/WARNING/STOP thresholds
- Final output screenshots
- Hardware photograph

## 5. Suggested first commit message

`Add CAN vehicle monitoring and driver assistance project`
